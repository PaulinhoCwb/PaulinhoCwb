## 👋 About me

I'm a **Full Stack Developer** from Curitiba, Brazil, building web systems from the database to the deploy.
I specialize in turning business problems into working software — especially where code meets the real world:

- 🏷️ **RFID systems** — reading, EPC generation and desktop integrations
- 🧾 **Fiscal APIs** — Brazilian electronic invoices (NF-e)
- 🛒 **E-commerce** and custom management systems
- ☁️ **Infra & deploy** — Docker, Kubernetes, DigitalOcean, monitoring with Sentry

> 💼 **Available for freelance projects and job opportunities.** Have a project in mind? [Let's talk!](mailto:joaopaulocap10@gmail.com)
